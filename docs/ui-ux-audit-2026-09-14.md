# UI/UX-аудит витрины — 2026-09-14

Объект: https://towary-dla-domu.com (прод, чёрный ящик).
Метод: Playwright (headless Chromium), desktop 1440×900 + mobile 390×844; на каждый тезис — скриншот и/или DOM-факт. Скриншоты: `gui-audit-screenshots/`. Консольные логи этапов: /tmp/pw-audit/logs (итог сведён ниже).
Ограничение: заказ не оформлялся (остановка перед «Підтвердити замовлення») — на прод данные не писались; корзина жилa только в localStorage headless-браузера.
Визуальные проверки выполнялись через анализ изображений и сверялись с DOM; пункты без DOM-подтверждения помечены «визуально».

Шкала: **P0** — блокирует бизнес-метрику/данные; **P1** — прямо влияет на конверсию; **P2** — качество/полировка.

## P0 — критично

### 1. CSP блокирует Google Analytics и Microsoft Clarity на всём сайте
На каждой странице (главная, каталог, карточка, корзина, чекаут, мобильные) в консоли:
```
Loading the script 'https://www.googletagmanager.com/gtag/js?id=G-3834R9JDFE'
violates the following Content Security Policy directive: "script-src 'self' 'unsafe-inline'". … blocked.
Loading the script 'https://www.clarity.ms/tag/yht030073x' … blocked.
```
`requestfailed: err=csp` для обоих. Все 18 консольных «ошибок» мобильного прогона — это эти два блока, других JS-ошибок нет.

**Эффект:** аналитика (GA G-3834R9JDFE + записи сессий Clarity) не собираются вообще. Владелец принимает решения вслепую; события `trackEvent` из кода тоже не доходят.
**Фикс:** в CSP `script-src` добавить `googletagmanager.com` (+ `google-analytics.com`), `clarity.ms`; в `connect-src` — эндпоинты GA/Clarity. Проверить в отчёте GA появление хитов.

### 2. Пустой результат поиска — нет empty-state
Запрос «zzxxqq123носкиф» → `/catalog?q=…`: пустая сетка, сайдбар фильтров остаётся, сообщения «Нічого не знайдено» нет (DOM: совпадений нет; скриншот `d19-search-empty-results.png`).
**Фикс:** блок «За запитом "…" нічого не знайдено» + советы (проверить раскладку, популярные категории/товары, ссылка на каталог). Образец хорошего empty-state уже есть в проекте — «Обране» (`d22-favorites-empty.png`).

### 3. Страница результатов поиска без заголовка и счётчика
`/catalog?q=шпалери`: **h1 отсутствует**, счётчик «Знайдено: N» отсутствует (DOM-факт, повторен на desktop и mobile; `d17-search-results.png`). На корне `/catalog` при этом есть и «Каталог товарів», и «Знайдено: 4565».
Пользователь не видит, что искал и сколько нашлось; SEO-заголовок тоже теряется.
**Фикс:** на выдаче показывать «Результати пошуку "шпалери"» (h1) + счётчик, как в каталоге.

## P1 — конверсия

### 4. Нет кнопки «В кошик» на карточках (каталог + главная)
Карточка = фото + название + цена + ♡ (`d02-catalog-full.png`, `d01-home-full.png`). При 4565 товарах каждая покупка требует захода в карточку.
**Фикс:** кнопка быстрого добавления на карточке (или на hover на desktop).

### 5. Нет старой цены / бейджей скидок на карточках
Зачёркнутая цена, «-20%», «Акція», «Новинка» — не отображаются нигде в списках (`d01`, `d02`). Провести распродажу визуально невозможно.

### 6. Слабая обратная связь добавления в корзину
После «Додати в кошик»: тоста нет, кнопка не меняет состояние. Есть: счётчик на иконке корзины (на скриншоте `d09` он неразличим для глаза — очень мелкий) и ссылка «У кошику — перейти» в бай-боксе (DOM: `aria-label="Кошик, товарів: 1"`, текст «1», ссылка 492×48px появилась). `d09b-after-toast-gone.png`.
**Фикс:** тост «Додано до кошика» с мини-превью и кнопкой «Оформити», и/или состояние кнопки «Додано ✓»; увеличить бейдж корзины.

### 7. Карточка товара бедная
У проверенных товаров (клей Quelyd, холодильник Haier): нет селектора количества (по 1 шт. за клик), одно фото без миниатюр/зума, секции «Характеристики» и «Відгуки» пустые (заглушки) — `d08-product-full.png`. Пустые характеристики на массовых товарах снижают доверие и SEO.

### 8. Телефон в чекауте необязателен
DOM: `input[type=tel] required=false` при обязательных имени/фамилии/email. Валидация телефона есть (частичный номер → «Вкажіть повний номер після +380», `d13d`), но пустой телефон пропускается. Для Новой Почты (особенно курьер) и разрешения вопросов по заказу телефон — основной канал в Украине.
**Рекомендация:** сделать телефон обязательным (минимум — для доставки курьером).

## P2 — полировка

9. **Фильтр цены молча отбрасывает невалидную границу.** «від = −50, до = 500» → «Застосувати» не применяет фильтр вовсе (URL без min/max, счётчик 4565), поле «від» очищается без сообщения (`d05-price-boundary.png`, `d06-price-applied.png`). С валидными значениями работает: 1000–3000 → 1233 товара, `?min=1000&max=3000` (`d06b`). Нужен inline-хинт «введіть ціну від 0».
10. **Главная, «Популярні товари»:** 6 карточек при сетке 4 в ряд → недозаполненный второй ряд; высоты карточек пляшут (`d01-home-full.png`).
11. **Белые предметы на белом фоне** карточек сливаются (Electrolux форма для льоду — почти невидима) (`d01-home-full.png`). Нужен фон/подложка под фото.
12. **Мобильная корзина:** qty-кнопки −/+ ~32px и впритык; × удаления близко к другим элементам (`m05-cart-viewport.png`).
13. **Мобайл, первый экран карточки:** «Додати в кошик» ниже фолда (`m04-product-viewport.png`); сабмит чекаута и «Фільтри» не sticky (`m06-checkout-full.png`, `m03-catalog-full.png`).
14. **Тексты:** «Ножі та **аксессуари**» в футере (норма — «аксесуари»); «ПОБУТОВА ТЕХНІКА» капсом среди строчных соседей (DOM-факт футера). В названиях шпалер встречается русизм «обои» («002-1 … обои оселя» — данные поставщика, видно в саджестах поиска `d16-search-suggest.png`).
15. **Иконка «Шукати»** в хедере заметно бледнее соседних иконок (computed color L≈65.9 против 35.6 у остальных) — визуально.
16. **404:** страница есть («Сторінку не знайдено», `d21-404.png`), но `<title>` остаётся generic «Товари для дому — Інтернет-магазин».

## Что работает хорошо

- **Скорость/SSR:** DOMContentLoaded главной ~280 мс; JS-ошибок, кроме CSP-блоков, нет ни на одной странице.
- **Семантика/доступность:** `lang=uk`; у всех 14 img главной есть alt (0 пустых); иконочные кнопки с `aria-label` («Кошик, товарів: N», «Обране, товарів: 0», «Відкрити меню»); поиск — combobox с `aria-expanded` и listbox «Пропозиції пошуку»; фильтры цены с `aria-label` «Ціна від/до».
- **Поиск:** живые саджесты с ценами и фото; спецсимволы/`<script>` безопасно энкодятся в URL, XSS-эха нет (`d20-search-specialchars.png`).
- **Каталог:** сортировка и пагинация синхронизированы с URL (`?sort=price_asc`, `?page=2`), фильтр цены/наличие/бренд работают, счётчик «Знайдено: N» обновляется (4565 → 1233).
- **Чекаут:** нативная валидация обязательных полей (фокус на первое невалидное), человекочитаемая ошибка телефона, прогрессивное раскрытие Новой Почты (місто → відділення), три оператора доставки + самовывоз, LiqPay-хинт, сводка с итогом (`d12`, `d13b`–`d14`).
- **Корзина:** qty −/+, × удаление, «Очистити кошик» вынесен мелким текстом от CTA, «Оформити замовлення» крупный синий (`d10-cart-full.png`).
- **Мобильный:** бургер-меню с категориями и карточками (`m02`), фильтры — bottom-sheet с Застосувати/Скинути (`m07`), каталог 2-в-ряд, чекаут одной колонкой.
- **Empty-state «Обране»** — образцовый: сообщение + CTA «Перейти до каталогу →» (`d22`).
- **Валюта единая** — «грн» везде (канон в `app/lib/format.ts`). Замеченные при визуальном анализе «₴» — артефакт чтения скриншотов, DOM-проверкой опровергнут.
