# `_du` → base permanent redirects (103 pairs) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve permanent redirects from 97 confirmed same-price `_du` product URLs to their base product URLs, exclude exactly those URLs from the sitemap, and leave the 6 price-diff pairs and 26 orphans untouched.

**Architecture:** A static, audit-derived allowlist module (97 redirect pairs + 6 price-diff pairs) is the single source of truth, generated by a read-only DB script. The product page consults it and calls `permanentRedirect` only when a verified base product actually exists. The sitemap filters redirected `_du` slugs to keep the "indexable set == sitemap set" invariant. DB, importer, and price/stock sync are NOT modified.

**Tech Stack:** Next.js App Router (`permanentRedirect` from `next/navigation` — 308, the permanent redirect of App Router; SEO-equivalent of 301 for crawlers), Supabase read-only queries, node:test.

**Spec:** READ-ONLY аудит 2026-08-31 (audit session): 103/103 pairs identity-confirmed (name/brand/category/images 100% equal); slug derivation verified 103/103 (`base_slug = du_slug` minus `_du` suffix); 0 orders reference `_du` products; 26 orphans have base only in the content feed.

## Global Constraints

- БД, importer (`app/lib/yugcontract/*`), скрипты импорта — НЕ менять.
- Товары не удалять; `products.yugcontract_id` не менять (price/stock sync зависит от `_du` позиций прайса).
- 26 `_du`-сирот не трогать: их yc-id НЕ входит в allowlist redirect'ов.
- 6 пар с разной ценой НЕ redirect'ить и основную цену не выбирать автоматически (обе цены задокументированы в сгенерированном модуле).
- Точная семантика 301 (а не 308) — только через `redirects` в `next.config` (Option B ниже); по умолчанию план использует `permanentRedirect` (308).

## Status code decision (301 vs 308)

`permanentRedirect` в App Router отдаёт **308 Permanent**. Для Google 301 и 308 эквивалентны (оба «permanent», сигналы индексации и склейки идентичны). Браузеры тоже. Если бизнесу нужен литеральный `301` — есть Option B (ниже), но она дороже в поддержке и теряет per-request guard «base существует». По умолчанию — Option A.

- [ ] **Step 1: Write the generator script**

Follow the project script style (see `scripts/yugcontract-rrp-apply.ts` for `.env.local` loading and service client). The generator reads the DB (SELECT only), re-verifies the audit invariants, and writes `app/lib/du-redirects.ts`. It must FAIL (exit 1) if the DB diverges from the audit — that is the safety gate.

```ts
/**
 * ONE-OFF GENERATOR (read-only DB): rebuild app/lib/du-redirects.ts from the
 * live audit data. Writes ONLY the generated module — never touches products,
 * importer tables, or any DB row.
 *
 * Safety gates (hard fail, exit 1) — the module is regenerated ONLY when the
 * DB still matches the 2026-08-31 audit:
 *   - exactly 103 `_du` products with an existing base;
 *   - exactly 26 `_du` orphans without a base;
 *   - 103/103 base_slug === du_slug minus the `_du` suffix;
 *   - base exists in content feed only for orphans (no new duplicates);
 *   - exactly 6 pairs with differing price.
 *
 * Usage: node --experimental-strip-types scripts/yugcontract-du-redirect-allowlist.ts
 */
import { readFileSync, writeFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import path from 'node:path';

const root = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..');
try {
  for (const line of readFileSync(path.join(root, '.env.local'), 'utf8').split('\n')) {
    const m = line.match(/^\s*([A-Z0-9_]+)\s*=\s*(.*)\s*$/);
    if (m && process.env[m[1]] === undefined) process.env[m[1]] = m[2];
  }
} catch {}

const { createClient } = await import('@supabase/supabase-js');
const svc = createClient(
  process.env.NEXT_PUBLIC_SUPABASE_URL!,
  process.env.SUPABASE_SERVICE_ROLE_KEY!, // service key OK: script-side only, read-only usage
  { auth: { persistSession: false } }
);

const AUDIT_DATE = '2026-08-31';
const PRICE_DIFF_YC = new Set([
  '6241811_du', '6849632_du', '6873343_du', '6988988_du', '7204300_du', '7270074_du',
]);
const stripDu = (s: string) => s.replace(/_du$/, '');

// 1. Load all du products with their base (LEFT JOIN by derived base yc id).
const { data, error } = await svc
  .from('products')
  .select('yugcontract_id, slug, price, base:yugcontract_id!self(...)') // see note below
```

The self-join above is not expressible in PostgREST — do TWO reads instead (keep it simple, script-side):

```ts
const { data: duRows, error: duErr } = await svc
  .from('products')
  .select('yugcontract_id, slug, price')
  .like('yugcontract_id', '%\\_du');
if (duErr || !duRows) throw new Error(duErr?.message ?? 'du read failed');

const { data: baseRows, error: baseErr } = await svc
  .from('products')
  .select('yugcontract_id, slug, price')
  .not('yugcontract_id', 'like', '%\\_du');
if (baseErr || !baseRows) throw new Error(baseErr?.message ?? 'base read failed');

const bases = new Map(baseRows.map((b) => [b.yugcontract_id, b]));

const pairs = duRows.flatMap((du) => {
  const base = bases.get(stripDu(du.yugcontract_id));
  if (!base) return []; // orphan — 26 expected, gated below
  return [{
    duYc: du.yugcontract_id, duSlug: du.slug,
    baseYc: base.yugcontract_id, baseSlug: base.slug,
    ...(du.price !== base.price
      ? { duPrice: du.price, basePrice: base.price } : {}),
  }];
});
const orphans = duRows.filter((du) => !bases.has(stripDu(du.yugcontract_id)));

// 2. Audit gates — every violation is a hard stop.
const fail = (msg: string) => { console.error('AUDIT GATE FAILED:', msg); process.exit(1); };
if (pairs.length !== 103) fail(`pairs ${pairs.length} !== 103`);
if (orphans.length !== 26) fail(`orphans ${orphans.length} !== 26`);
if (pairs.some((p) => p.baseSlug !== stripDu(p.duSlug))) fail('slug derivation changed');
const priceDiff = pairs.filter((p) => p.duPrice !== undefined);
if (priceDiff.length !== 6) fail(`price-diff ${priceDiff.length} !== 6`);
if (priceDiff.some((p) => !PRICE_DIFF_YC.has(p.duYc))) fail('price-diff set changed');

// 3. Emit the module (97 redirect pairs = pairs minus 6 price-diff).
const redirect = pairs.filter((p) => p.duPrice === undefined)
  .sort((a, b) => a.duYc.localeCompare(b.duYc));
const diff = priceDiff.sort((a, b) => a.duYc.localeCompare(b.duYc));
const q = JSON.stringify;
const emit = (list: typeof redirect, withPrices: boolean) => list.map((p) => `  {
    duYc: ${q(p.duYc)}, duSlug: ${q(p.duSlug)},
    baseYc: ${q(p.baseYc)}, baseSlug: ${q(p.baseSlug)},${withPrices
      ? `\n    duPrice: ${q(p.duPrice!)}, basePrice: ${q(p.basePrice!)},` : ''}
  }`).join(',\n');

const out = `/**
 * GENERATED by scripts/yugcontract-du-redirect-allowlist.ts on audit ${AUDIT_DATE}.
 * DO NOT EDIT BY HAND — regenerate instead. Read-only audit source:
 * 103 verified _du↔base pairs (name/brand/category/images 100% equal).
 * ${redirect.length} same-price pairs -> permanent redirect to base.
 * ${diff.length} price-diff pairs -> documented here ONLY, never redirected
 * (business decision pending; both prices kept for the decision).
 * The 26 _du orphans are intentionally absent from both lists.
 */
export interface DuRedirectPair {
  duYc: string; duSlug: string; baseYc: string; baseSlug: string;
  duPrice?: string; basePrice?: string;
}

export const DU_ALLOWLIST_AUDIT_DATE = ${q(AUDIT_DATE)} as const;

export const DU_REDIRECT_PAIRS: readonly DuRedirectPair[] = [
${emit(redirect, false)},
];

export const DU_PRICE_DIFF_PAIRS: readonly DuRedirectPair[] = [
${emit(diff, true)},
];

export const DU_REDIRECT_BY_YC: ReadonlyMap<string, DuRedirectPair> = new Map(
  DU_REDIRECT_PAIRS.map((p) => [p.duYc, p])
);

export const DU_REDIRECT_SLUGS: ReadonlySet<string> = new Set(
  DU_REDIRECT_PAIRS.map((p) => p.duSlug)
);
`;
writeFileSync(path.join(root, 'app/lib/du-redirects.ts'), out);
console.log(`OK: wrote app/lib/du-redirects.ts (${redirect.length} redirect, ${diff.length} price-diff, ${orphans.length} orphans untouched)`);
```

### Task 4: Tests for the allowlist and wiring

- [ ] **Step 1: Write the tests**

```ts
/**
 * _du → base redirect allowlist (audit 2026-08-31):
 * invariants of the generated module + source-level wiring checks:
 * the product page redirects ONLY allowlisted pairs (never the 6 price-diff
 * pairs, never the 26 orphans) and the sitemap excludes exactly those slugs.
 */
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { readFileSync } from 'node:fs';
import {
  DU_REDIRECT_PAIRS, DU_PRICE_DIFF_PAIRS, DU_REDIRECT_BY_YC, DU_REDIRECT_SLUGS,
} from '../app/lib/du-redirects.ts';

test('DU: allowlist counts match the audit (97 redirect + 6 price-diff)', () => {
  assert.equal(DU_REDIRECT_PAIRS.length, 97);
  assert.equal(DU_PRICE_DIFF_PAIRS.length, 6);
});

test('DU: every pair is well-formed (_du slug strips exactly to base slug)', () => {
  for (const p of [...DU_REDIRECT_PAIRS, ...DU_PRICE_DIFF_PAIRS]) {
    assert.ok(p.duYc.endsWith('_du'), p.duYc);
    assert.ok(!p.baseYc.endsWith('_du'), p.baseYc);
    assert.equal(p.duSlug, `${p.baseSlug}_du`, p.duSlug);
    assert.notEqual(p.duSlug, p.baseSlug);
  }
});

test('DU: no duplicate keys, price-diff never overlaps the redirect set', () => {
  const ycs = [...DU_REDIRECT_BY_YC.keys()];
  assert.equal(new Set(ycs).size, ycs.length);
  for (const p of DU_PRICE_DIFF_PAIRS) {
    assert.ok(!DU_REDIRECT_BY_YC.has(p.duYc), `${p.duYc} must not redirect`);
  }
});

test('DU: price-diff pairs carry both prices for the pending decision', () => {
  for (const p of DU_PRICE_DIFF_PAIRS) {
    assert.ok(p.duPrice && p.basePrice && p.duPrice !== p.basePrice, p.duYc);
  }
});

test('DU: page redirects only via the allowlist and guards base existence', () => {
  const src = readFileSync('app/product/[slug]/page.tsx', 'utf8');
  assert.match(src, /permanentRedirect/);
  assert.match(src, /DU_REDIRECT_BY_YC\.get/);
  // Guard: redirect fires only when the base product resolves.
  assert.match(src, /if \(baseProduct\) permanentRedirect/);
});

test('DU: sitemap filters redirected slugs', () => {
  const src = readFileSync('app/sitemap.ts', 'utf8');
  assert.match(src, /DU_REDIRECT_SLUGS\.has/);
});
```

## Option B (only if literal 301 is mandated): `next.config` redirects

Generate 97 static entries with `statusCode: 301` from the same allowlist (write a JSON file `app/lib/du-redirects.json` in Task 1 additionally, then in `next.config.ts`):

```ts
import duRedirects from './app/lib/du-redirects.json';
// ...
const nextConfig: NextConfig = {
  // ...
  async redirects() {
    return duRedirects.pairs.map((p) => ({
      source: `/product/${p.duSlug}`,
      destination: `/product/${p.baseSlug}`,
      statusCode: 301,
    }));
  },
};
```

Trade-offs: true 301 at the edge, zero per-request cost; but no base-exists guard (stale entries can 301 into a 404), the JSON must stay in sync with the `.ts` module, and `next.config.ts` importing local modules is version-sensitive in this Next distribution — verify with `npm run build` before adopting. The sitemap filter (Task 3) is required in BOTH options.
