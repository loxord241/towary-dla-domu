# Інструкція для спеціаліста 1С (постачальник «Слав обои»)

Що це: щоденна автоматична выгрузка списку товарів (код, назва, роздрібна
ціна, залишок) з бази 1С 7.7 та відправка файлу інтернет-магазину.
Скрипт **тільки читає** базу — нічого не змінює.

## Що потрібно зробити один раз (~20 хвилин)

1. **Користувач тільки-читання.** Створіть у базі користувача `vygruzka`
   (без адмінських прав — мінімальний інтерфейс, заборона на редагування).
   Пароль впишіть у скрипт (`USER_PASS`).
   *Чому не адмін: пароль зберігається у файлі на цьому ПК у відкритому
   вигляді; скрипту достатньо прав читання.*
2. **Заповніть блок КОНФІГ** на початку `slav-oboi-export.vbs`:
   - `BASE_PATH` — шлях до папки бази 1С;
   - `USER_NAME` / `USER_PASS` (якщо у користувача немає пароля — залиште
     `USER_PASS = ""`, скрипт сам не додасть параметр /P; якщо в базі взагалі
     немає списку користувачів — залиште порожніми обидва);
   - `UPLOAD_KEY` — ключ, який видає магазин (до його видачі залиште як є:
     тестовий запуск все одно збереже CSV локально).
3. **Секції [CONFIG-SPECIFIC]** у тілі скрипта — звірте імена метаданих
   з вашою конфігурацією (ПУБ/ТиС називають по-різному):
   - довідник номенклатури та його реквізити (артикул, одиниця);
   - підпорядкований довідник цін + тип ціни «Роздрібна»
     (**закупівельну ціну скрипт не вивантажує**);
   - ресурс кількості регістра залишків (у ПУБ, можливо, залишок треба
     брати через бухгалтерські підсумки рахунку 28 — тоді 3-5 рядків
     заміни в `BuildCsv`).
4. **Тестовий запуск** (з-під користувача, який має право запускати 1С):
   ```
   C:\Windows\SysWOW64\cscript.exe //Nologo slav-oboi-export.vbs
   ```
   У папці має з'явитися `РРРРММДД-wallpapers.csv` + запис `OK:` у лог.
   **ВАЖЛИВО: запускати саме 32-бітний cscript** (шлях вище) — 1С 7.7
   32-бітна, звичайний 64-бітний wscript OLE не створить.
5. **Планувальник Windows (Windows 10 Корпоративна):**
   - Task Scheduler → Create Task;
   - Trigger: щодня, 14:00;
   - Action: запуск `C:\Windows\SysWOW64\cscript.exe` з аргументами
     `//Nologo "<повний шлях>\slav-oboi-export.vbs"`;
   - ✅ «Run task as soon as possible after a scheduled start is missed» —
     якщо ПК був вимкнений у 14:00, выгрузка виконається при увімкненні;
   - запуск «Тільки коли користувач увійшов» (1С 7.7 через OLE під
     службовим акаунтом може не ініціалізуватись — це нормально;
     якщо ПК без автологіна — залиште цей режим).

## Що бачить магазин

- POST `text/csv` (UTF-8, роздільник `;`) на
  `https://towary-dla-domu.com/api/ingest/1c-wallpaper` з ключем у заголовку.
- Очікуємо **щодня близько 14:00**; якщо файл не прийшов — магазин
  нагадає (перший тиждень — контрольна звірка щодня).
- Лог `slav-oboi-export.log` поруч зі скриптом — дивитись при будь-яких
  проблемах; останній вдалий CSV залишається у папці як резервна копія.

## Контакт

Питання по приймаючій стороні — власник магазину (передає контакти).
